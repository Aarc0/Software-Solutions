# Decisiones

 ## TailwindCSS

 **Estado:** Aceptada
 **Fecha:** 1/10/2026

 **Descripción**
 Se ha decidido implementar TailWind css para el desarrollo del frontend por motivos estéticos ya que permite una personalización limpia y cuidada siendo fácil de implementar y trabajar. Además se considera que no modifica ni interfiere con la línea base del proyecto ya que solo se implementa con el objetivo de mejorar la estética de la aplicación.
 Además se ha llevado a cabo porque los **integrantes** con más experiencia en el desarrollo web han usado esta tecnlogía previamente y estan más familiarizados con ella, mientras que los demás al no tener prácticamente experiencia les resulta indiferente aprender algo sobre esta tecnología a aprender sobre css puro

 ## Datos De prueba

 **Estado:** Aceptada
 **Fecha:** 5/10/2026

 **Descripcion**
 Se ha decidido subir al repositorio una clase que inicializa una serie de datos de prueba en la base de datos, de esta manera todos los integrantes tienen la misma información por defecto. De esta manera se pueden testear ciertas funcionalidades. La documentación de la clase `DataInitializer` se encuentra en [`docs/technical/domain.md`](docs/technical/domain.md).
