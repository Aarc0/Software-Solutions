## Objetivo

Desarrollar una plataforma para la gestión de alquiler de viviendas siguiendo un proceso iterativo e incremental de ingeniería del software

## Estado

Sprint 0 - Preparación y planificación
Sprint 1 - Desarrollo de las primeras parte de la 1º Issue
Sprint 2 - Finalización de la 1º Issue y comienzo del desarollo de las siguientes

## Construcción y ejecución

Requisitos:

- Java 17

Comandos:
.\mvnw.cmd clean
.\mvnw.cmd test
.\mvnw.cmd package
.\mvnw.cmd verify
.\mvnw.cmd spring-boot:run

URL local:
http://localhost:8080
